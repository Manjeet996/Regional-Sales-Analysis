# Regional Sales Analysis

A data analytics project exploring historical U.S. regional sales performance from **2014 to 2018**. The project brings together exploratory data analysis, an interactive Power BI dashboard, and a presentation to examine sales, profitability, products, customers, regions, and sales channels.

## Project Overview

The objective of this project is to turn regional sales data into useful business insights. The analysis focuses on how sales and profit vary over time and across regions, states, product categories, customers, and sales channels.

The repository includes the dataset, an exported CSV, a Jupyter Notebook for exploratory data analysis (EDA), a Power BI report, and a presentation.

## Business Questions

The project is designed to explore questions such as:

- How do sales and profit change over the 2014–2018 period?
- Which regions and states contribute to sales and profitability?
- Which products and product categories perform strongly?
- How do customers and sales channels contribute to overall performance?
- Are there seasonal patterns or changes in sales over time?
- How do actual sales compare with budget measures where available?

## Tools & Technologies

- **Python** — exploratory data analysis
- **Pandas and NumPy** — data handling and analysis
- **Matplotlib and Seaborn** — data visualization
- **Jupyter Notebook / Google Colab** — analysis environment
- **Microsoft Power BI** — interactive reporting and dashboarding
- **Microsoft Excel** — dataset review and data handling
- **Microsoft PowerPoint** — presentation of the analysis

## Analysis Workflow

1. Review the source dataset and understand its fields.
2. Prepare and explore the data using Python.
3. Analyze sales and profitability across time, geography, products, customers, and channels.
4. Build and review the Power BI report.
5. Present the analysis and business questions in the project presentation.

## How to Explore

1. Download or clone this repository.
2. Open `Regional_Sales_Analysis_EDA.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
3. If prompted, update the notebook's dataset path to the location of the CSV or Excel file on your computer.
4. Open `Regional_Sales_Analysis_Dashboard.pbix` using Microsoft Power BI Desktop.
5. Review the presentation for a summarized view of the project.
